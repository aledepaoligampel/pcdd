The problem

AI coding fails in two opposite ways.

Most teams swing between them. One fix gets a ten-page spec; the next risky migration gets a prompt and a prayer.

Too little process

Fast today. Lost tomorrow.

  • A new session forgets what was decided and why.
  • “Done” means it compiled, not that it works.
  • Risky changes get the same treatment as typos.
Too much process

Safe on paper. Skipped in practice.

  • A full spec for a one-line fix.
  • Ceremony burns context, tokens and patience.
  • So people stop following it — even when it matters.
PCDD

Process proportional to risk.

  • Small, clear work goes straight through.
  • Substantial work gets approved specs and a record.
  • Risky work gets independent review before commit.

Continuity

Close the laptop.
Keep the context.

Every substantial change lives in one Markdown file in your repo: specs, tasks, evidence and the exact next step. A fresh session — or a different agent — reads that, not your entire history.

Small starting context. Skills load only when needed. No external memory service.

Get started

Three steps.
Nothing new to learn.

No new app, no account, no config to write. You keep using your agent the way you already do.

  1. 1

    Install once

    $ curl -fsSL https://pcdd.dev/install.sh | sh

    One line. Installs uv if it’s missing. Python 3.9+, zero runtime dependencies.

  2. 2

    Add it to your project

    $ pcdd init

    Preview first with --dry-run. Your own content is preserved, and pcdd rollback undoes it.

  3. 3

    Just describe the change

    “Add rate limiting to the login endpoint.”

    Open Codex, Claude Code or Antigravity. The agent picks the right amount of process and asks only what it needs.

You stay in charge

The agent proposes.
You decide.

You approve the specs

Verifiable criteria, with your words quoted, before any code is written.

Evidence, not vibes

Test-first when the result is clear; otherwise the record says what remains unverified.

No surprise commits

Commits, pushes and publishing need your explicit go-ahead. No AI attribution added.

Yours, locally

Plain Markdown in your repo. Preview, update and roll back installs. No service, no lock-in.
